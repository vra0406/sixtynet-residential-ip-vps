## 三个必须先知道的限制

**80 和 443 端口不开放。** 官方给的理由是 IP 风险控制，这条直接印在产品说明里，几份不同时间的测评也一致。要建站得在前面挂反向代理、CDN 或者中转，直接用 IP 起 HTTP 服务是不行的。

**官方屏蔽 ICMP。** 你 ping 不通自己的机器，第三方测评也拿不到 ping 数据。判断线路只能靠 traceroute、iperf3 或者实际业务跑起来看，所有关于这家的「平均延迟 XXX ms」都要先问一句是怎么测的。

**注册要过手机验证，支付不支持支付宝。** 有反馈说 +86 号码收不到验证码，手边最好准备一个能收码的非大陆号码。付款走 PayPal 或信用卡。

这三条决定了使用姿势：拿到机器第一件事是配 SSH 密钥和代理，不是装面板。

## 线路：三个 IP 运营商，三套结果

线路要按 IP 运营商分开看。同一天下单的两台机器，IP 段不同，路由就不一样。

**AT&T Mobility 段（2024 年 8 月测评）**：三网去程都是直连洛杉矶，联通过圣何塞转 TATA，移动过圣何塞接 PCCW；回程三网统一走 CN2，电信段是 59.43。这是「三网 CN2 回程」说法的来源。

**Cox Communications 段（2025 年 10 月测评）**：去程电信走 CN2 直连洛杉矶，联通直连后接 GTT，移动直连洛杉矶；回程电信 CN2，联通 AS10099 + AS9929，移动强制走电信 CN2。

**Wave / Astound 段（2026 年 2 月测评）**：标称电信联通 9929 + 移动 CMIN2。这台的实测数据最能说明问题：联通上海 5G 上传 61.99 / 下载 163.32Mbps、延迟 170.58ms；电信苏州 10.22 / 20.65Mbps、153.39ms；电信镇江 5.42 / 6.31Mbps、148.20ms；移动苏州 10.60 / 0.20Mbps、275.30ms。同一台机器在洛杉矶本地是 355.83 / 202.95Mbps、8.78ms，跑 Speedtest.net 是 1401.66 / 957.38Mbps、7.87ms。

iperf3 更直白：深圳电信 500M 打到 65.8Mbps，重传 2268 次；济南联通 500M 打到 118Mbps；广东移动 1000M 只有 37.2Mbps。测评者的结论是出口能跑 7Gbps，落到具体中转机器大多只有 400–500Mbps，回国方向三网基本 50Mbps 上下，电信还有掉到 10Mbps 并断流的情况。

延迟数字不难看，带宽撑不住。当落地机够用，当线路机不够。

「三网 CN2 GIA 回程」这个说法要带时间戳。2024 年的 AT&T 段确实是三网回程 CN2，2026 年 2 月的 Wave 段已经是 9929 加 CMIN2。线路跟着 IP 段走，别人的测评结果不能直接套到你手上这台。
